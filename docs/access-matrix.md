# Матрица доступа

| Действие | Неавторизованный | Автор | Респондент |
| --- | --- | --- | --- |
| Регистрация / логин | Да | Да | Да |
| Создание опроса | Нет | Да | Да |
| Просмотр своих опросов | Нет | Да | Да |
| Редактирование черновика | Нет | Только своего | Нет |
| Управление вопросами и вариантами | Нет | Только в своём `draft` | Нет |
| Публикация / закрытие | Нет | Только своего | Нет |
| Получение опубликованного опроса | Нет | Да | Да |
| Отправка ответов | Нет | Да | Да |
| Повторное прохождение | Нет | Нет | Нет |
| Просмотр аналитики | Нет | Только автор опроса | Нет |

Примечание: один и тот же пользователь может одновременно выступать автором и респондентом. Роль определяется действием, а не отдельным полем в таблице пользователей.
